# Security and data scope

This repository is a synthetic-data portfolio example. Do not add production,
client, employer or personal data, credentials, OAuth tokens, Script
Properties, API keys, `.clasp.json` or a real `appsscript.json` file.

The bundled Gemini adapter is disabled by default. Enabling an external model
requires a separate review of the current API, model, pricing, data terms and
the exact data fields to be transmitted.

The repository does not grant access to the private Google Sheet, bound Apps
Script project or Owner-only AppSheet prototype used for validation.
